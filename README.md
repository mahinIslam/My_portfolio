# Mahin Islam — AI Solutions Lead Portfolio

A responsive, animated portfolio built using **plain HTML, CSS and JavaScript**. No build tools required.

## Getting started

1. Unzip the archive.
2. Open `index.html` in Chrome, Safari, Firefox or Edge.
3. For development, you can serve the folder using `python3 -m http.server 8000` and visit http://localhost:8000.

## Features

- Responsive dark/light interface with theme preference saved locally
- Animated hero illustration and rotating roles
- Interactive, keyboard-operable 3D flip cards
- Filterable project gallery with project-detail dialogs
- Interactive workflow explanation
- Professional and academic timeline
- Direct contact links for email, LinkedIn, WhatsApp and GitHub (no contact form)
- Reduced-motion support and semantic page structure

## Customise

- Change contact details, biography, educational background and layout text in `index.html`.
- Edit capability cards, sample project data and workflow stages in `script.js`.
- Adjust design tokens near the top of `styles.css`.
- Replace illustrative projects with *verified* personal work before publishing them as case studies. The current project cards are explicitly labelled as concepts.
- Add real profile, demo or publication URLs only when they are available and verified.

## Hosting

Upload all files in this folder to any static hosting platform, e.g. GitHub Pages, Netlify, Cloudflare Pages or a standard web host. Set the publish directory to the project root.
